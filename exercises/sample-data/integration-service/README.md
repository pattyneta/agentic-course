# cruise-sync-service (day 5 review target)

A deliberately imperfect slice of a booking-supplier integration: it pulls cruise
inventory from a third-party API into the CMS and handles supplier webhooks.

**This code is the input for the Day 5 capstone** — a Managed Agents code-review
agent audits it. It contains a number of planted issues (reliability, security,
correctness). Don't fix them; the agent's job is to find them.
